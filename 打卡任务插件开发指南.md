# 打卡任务插件开发指南

## 一、插件架构概览

### 1.1 整体架构

打卡任务插件系统采用**插件化设计**，允许开发者创建可复用的任务模块。系统主要由以下几个部分组成：

```
┌─────────────────────────────────────────────────────────────┐
│                    打卡计划编辑器                           │
│  ┌──────────────┐    ┌──────────────────────────────────┐ │
│  │   任务面板    │    │           画布区域                │ │
│  │ (TaskPalette)│    │   (PlanCanvas)                  │ │
│  │  - 已安装任务  │    │   - 节点(Node)                 │ │
│  │  - 可拖拽     │    │   - 连线(Edge)                 │ │
│  └──────────────┘    └──────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    任务执行引擎                             │
│  ┌──────────────────────────────────────────────────────┐  │
│  │           TaskView (任务视图)                        │  │
│  │  - 启动任务                                          │  │
│  │  - 执行任务逻辑                                      │  │
│  │  - 完成任务                                          │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    插件注册表                               │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐            │
│  │ 插件1      │ │ 插件2      │ │ 插件3      │            │
│  │ (刷题)     │ │ (阅读)     │ │ (运动)     │            │
│  └────────────┘ └────────────┘ └────────────┘            │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心组件职责

| 组件 | 职责 | 文件路径 |
|------|------|----------|
| CheckinPanel | 主面板，展示计划列表 | `src/renderer/plugins/builtin/components/CheckinPanel.vue` |
| CheckinPlanEditor | 计划编辑器，包含任务面板和画布 | `src/renderer/plugins/builtin/components/CheckinPlanEditor.vue` |
| CheckinTaskPalette | 任务面板，展示可拖拽的任务 | `src/renderer/plugins/builtin/components/CheckinTaskPalette.vue` |
| CheckinPlanCanvas | 画布区域，节点和连线的渲染 | `src/renderer/plugins/builtin/components/CheckinPlanCanvas.vue` |
| CheckinNode | 节点组件 | `src/renderer/plugins/builtin/components/CheckinNode.vue` |
| CheckinEdge | 连线组件 | `src/renderer/plugins/builtin/components/CheckinEdge.vue` |
| CheckinTaskView | 任务执行视图 | `src/renderer/plugins/builtin/components/CheckinTaskView.vue` |

### 1.3 数据流转

```
1. 用户在编辑器中创建计划
    ↓
2. 从任务面板拖拽任务到画布 → 创建 PlanNode
    ↓
3. 连接节点 → 创建 PlanEdge（定义任务顺序关系）
    ↓
4. 保存计划 → 存储到 localStorage
    ↓
5. 执行计划 → 打开 CheckinRoadmap
    ↓
6. 点击任务 → 打开 CheckinTaskView
    ↓
7. 完成任务 → 更新 PlanNode.completed 状态
```

## 二、核心数据结构

### 2.1 CheckinTask（任务模板）

```typescript
export interface CheckinTask {
  id: string              // 任务唯一标识
  name: string            // 任务名称
  icon: string            // 图标（emoji）
  description: string     // 任务描述
  difficulty: 'easy' | 'medium' | 'hard'  // 难度
  category: string        // 分类：编程、学习、健康、习惯、其他
  downloads: number       // 下载量
  version: string         // 当前版本
  latestVersion: string   // 最新版本
  hasUpdate: boolean      // 是否有更新
  sourceUrl: string       // 源项目地址
  readme: string          // 说明文档（Markdown）
}
```

### 2.2 PlanNode（画布节点）

```typescript
export interface PlanNode {
  id: string              // 节点唯一标识
  taskId: string          // 关联的任务模板ID
  taskName: string        // 任务名称
  category: string        // 任务分类
  x: number               // 画布X坐标
  y: number               // 画布Y坐标
  completed: boolean      // 是否已完成
  completedAt?: string    // 完成时间
}
```

### 2.3 PlanEdge（连线）

```typescript
export interface PlanEdge {
  id: string              // 连线唯一标识
  sourceNodeId: string    // 源节点ID
  targetNodeId: string    // 目标节点ID
  type: 'main' | 'branch' | 'side'  // 连线类型
}
```

### 2.4 CheckinPlan（打卡计划）

```typescript
export interface CheckinPlan {
  id: string              // 计划唯一标识
  name: string            // 计划名称
  description: string     // 计划描述
  createdAt: string       // 创建时间
  nodes: PlanNode[]       // 节点列表
  edges: PlanEdge[]       // 连线列表
}
```

### 3.2 步骤二：创建任务执行视图组件

创建一个新的组件来处理任务的执行逻辑：

```vue
<!-- src/renderer/plugins/builtin/components/QuizTaskView.vue -->
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { Check, Clock, Target, Star } from 'lucide-vue-next'
import { useCheckinStore } from '@/stores/checkin'
import { useEditorStore } from '@/stores/editor'

const props = defineProps<{
  planId: string
  taskId: string
  taskName: string
}>()

const checkinStore = useCheckinStore()
const editorStore = useEditorStore()

const isCompleting = ref(false)
const completionTime = ref(0)
const showComplete = ref(false)

// 任务执行状态
const questionsCompleted = ref(0)
const totalQuestions = ref(10)  // 默认值，实际应从参数获取

let timer: number | null = null

function startTimer() {
  isCompleting.value = true
  completionTime.value = 0
  timer = window.setInterval(() => {
    completionTime.value++
  }, 1000)
}

function completeQuestion() {
  if (questionsCompleted.value < totalQuestions.value) {
    questionsCompleted.value++
  }
}

function completeTask() {
  if (timer) {
    clearInterval(timer)
    timer = null
  }
  isCompleting.value = false
  showComplete.value = true
  
  checkinStore.completeTask(props.planId, props.taskId)
  
  setTimeout(() => {
    editorStore.closeTab(`checkin:task:${props.taskId}`)
  }, 1500)
}

function formatTime(seconds: number) {
  const mins = Math.floor(seconds / 60)
  const secs = seconds % 60
  return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`
}

onMounted(() => {
  startTimer()
})
</script>

<template>

        <p class="text-vscode-text-secondary mt-2">专注完成刷题任务</p>
      </div>

        <div class="flex items-center justify-center mb-4">
          <Clock class="w-6 h-6 text-vscode-icon mr-2" />

        </div>
        <div class="text-center text-sm text-vscode-text-secondary">
          已专注 {{ completionTime }} 秒
        </div>
      </div>

      <div class="bg-vscode-hover rounded-lg p-6 mb-6">
```

### 4.4 创建参数配置表单组件

创建一个用于配置任务参数的组件：

```vue
<!-- src/renderer/plugins/builtin/components/TaskParamForm.vue -->
<script setup lang="ts">
import { reactive, watch } from 'vue'
import type { TaskParam } from '@/types/checkin'

const props = defineProps<{
  params: TaskParam[]
  modelValue?: Record<string, unknown>
}>()

const emit = defineEmits<{
  (e: 'update:modelValue', value: Record<string, unknown>): void
}>()

const localParams = reactive<Record<string, unknown>>({})

// 初始化默认值
props.params.forEach(param => {
  localParams[param.key] = props.modelValue?.[param.key] ?? param.default
})

// 监听外部变化
watch(() => props.modelValue, (newValue) => {
  if (newValue) {
    Object.assign(localParams, newValue)
  }
}, { deep: true })

function updateParam(key: string, value: unknown) {
  localParams[key] = value
  emit('update:modelValue', { ...localParams })
}
</script>

<template>
  <div class="space-y-4">
    <div
      v-for="param in params"
      :key="param.key"
      class="flex flex-col"
    >
      <label class="text-sm font-medium text-vscode-text-secondary mb-1">
        {{ param.name }}
      </label>
      
      <!-- 数字输入 -->
      <input
        v-if="param.type === 'number'"
        type="number"
        :value="localParams[param.key]"
        :min="param.min"
        :max="param.max"
        :placeholder="param.placeholder"
        class="px-3 py-2 rounded-lg bg-vscode-bg border border-vscode-border text-vscode-text focus:outline-none focus:border-vscode-active"
        @input="updateParam(param.key, Number(($event.target as HTMLInputElement).value))"
      />
      
      <!-- 文本输入 -->
      <input
        v-else-if="param.type === 'string'"
        type="text"
        :value="localParams[param.key]"
        :placeholder="param.placeholder"
        class="px-3 py-2 rounded-lg bg-vscode-bg border border-vscode-border text-vscode-text focus:outline-none focus:border-vscode-active"
        @input="updateParam(param.key, ($event.target as HTMLInputElement).value)"
      />
      
      <!-- 下拉选择 -->
      <select
        v-else-if="param.type === 'select'"
        :value="localParams[param.key]"
        class="px-3 py-2 rounded-lg bg-vscode-bg border border-vscode-border text-vscode-text focus:outline-none focus:border-vscode-active"
        @change="updateParam(param.key, ($event.target as HTMLSelectElement).value)"
      >
        <option
          v-for="option in param.options"
          :key="option.value"
          :value="option.value"
        >
          {{ option.label }}
        </option>
      </select>
      
      <!-- 布尔开关 -->
      <label
        v-else-if="param.type === 'boolean'"
        class="flex items-center space-x-3 cursor-pointer"
      >
        <input
          type="checkbox"
          :checked="localParams[param.key] === true"
          class="w-4 h-4 rounded text-vscode-active"
          @change="updateParam(param.key, ($event.target as HTMLInputElement).checked)"
        />
        <span class="text-sm text-vscode-text">启用</span>
      </label>
    </div>
  </div>
</template>
```

### 4.6 在编辑器中支持参数配置

修改 `CheckinPlanCanvas.vue`，当用户双击节点或右键菜单时显示参数配置：

```typescript
// CheckinPlanCanvas.vue - 添加参数配置逻辑
import TaskParamForm from './TaskParamForm.vue'
import { ref } from 'vue'

const showParamModal = ref(false)
const selectedNodeForParams = ref<PlanNode | null>(null)

function openParamModal(node: PlanNode) {
  selectedNodeForParams.value = node
  showParamModal.value = true
}

function saveParams(params: Record<string, unknown>) {
  if (selectedNodeForParams.value) {
    selectedNodeForParams.value.params = params
    pushUndo()
  }
  showParamModal.value = false
}

// 在右键菜单中添加"配置参数"选项
function handleContextMenu(e: MouseEvent) {
  e.preventDefault()
  const target = e.target as HTMLElement
  
  if (canvasState.selectedEdgeId) {
    canvasState.showContextMenu = true
    canvasState.contextMenuX = e.clientX
    canvasState.contextMenuY = e.clientY
    canvasState.contextMenuTarget = 'edge'
  } else if (canvasState.selectedNodeId) {
    // 检查选中的节点是否有参数配置
    const node = localNodes.value.find(n => n.id === canvasState.selectedNodeId)
    const task = checkinStore.installedTasks.find(t => t.id === node?.taskId)
    
    if (task?.params && task.params.length > 0) {
      canvasState.showContextMenu = true
      canvasState.contextMenuX = e.clientX
      canvasState.contextMenuY = e.clientY
      canvasState.contextMenuTarget = 'node'
    }
  }
}
```

### 4.7 在任务执行时使用参数

修改任务执行视图，从节点中读取参数：

```vue
<!-- src/renderer/plugins/builtin/components/QuizTaskView.vue -->
<script setup lang="ts">
import { ref, computed, onMounted } from 'vue'
import { Check, Clock, Target, Star } from 'lucide-vue-next'
import { useCheckinStore } from '@/stores/checkin'
import { useEditorStore } from '@/stores/editor'

const props = defineProps<{
  planId: string
  taskId: string
  taskName: string
}>()

const checkinStore = useCheckinStore()
const editorStore = useEditorStore()

const isCompleting = ref(false)
const completionTime = ref(0)
const showComplete = ref(false)

const questionsCompleted = ref(0)

// 从节点参数中获取配置
const nodeParams = computed(() => {
  const plan = checkinStore.myPlans.find(p => p.id === props.planId)
  const node = plan?.nodes.find(n => n.id === props.taskId)
  return node?.params || {}
})

// 使用参数，提供默认值
const totalQuestions = computed(() => {
  return (nodeParams.value.questionCount as number) || 10
})

const difficulty = computed(() => {
  return (nodeParams.value.difficulty as string) || 'medium'
})

const isTimed = computed(() => {
  return (nodeParams.value.timed as boolean) !== false
})

let timer: number | null = null

function startTimer() {
  if (isTimed.value) {
    isCompleting.value = true
    completionTime.value = 0
    timer = window.setInterval(() => {
      completionTime.value++
    }, 1000)
  }
}

function completeQuestion() {
  if (questionsCompleted.value < totalQuestions.value) {
    questionsCompleted.value++
  }
}

function completeTask() {
  if (timer) {
    clearInterval(timer)
    timer = null
  }
  isCompleting.value = false
  showComplete.value = true
  
  checkinStore.completeTask(props.planId, props.taskId)
  
  setTimeout(() => {
    editorStore.closeTab(`checkin:task:${props.taskId}`)
  }, 1500)
}

function formatTime(seconds: number) {
  const mins = Math.floor(seconds / 60)
  const secs = seconds % 60
  return `${mins.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`
}

onMounted(() => {
  startTimer()
})
</script>
```

## 六、常见问题

### Q1: 如何在任务执行时获取参数？

```typescript
// 从 store 中获取计划和节点
const plan = checkinStore.myPlans.find(p => p.id === planId)
const node = plan?.nodes.find(n => n.id === taskId)
const params = node?.params || {}

// 使用参数
const count = params.questionCount || 10
```

### Q2: 参数如何持久化？

参数会自动随 `PlanNode` 一起保存到 `localStorage`，无需额外处理。

### Q3: 如何支持动态参数验证？

可以在参数配置表单中添加自定义验证逻辑：

```typescript
function validateParam(key: string, value: unknown): boolean {
  const param = task.params?.find(p => p.key === key)
  if (!param) return true
  
  if (param.type === 'number') {
    const numValue = Number(value)
    if (param.min !== undefined && numValue < param.min) return false
    if (param.max !== undefined && numValue > param.max) return false
  }
  
  return true
}
```

### Q4: 如何支持复杂参数类型？

可以扩展 `TaskParam` 类型支持更复杂的参数，如数组、对象等：

```typescript
export interface TaskParam {
  // ... 现有字段
  type: 'number' | 'string' | 'select' | 'boolean' | 'array' | 'object'
  schema?: unknown  // 用于复杂类型的验证
}
```

## 七、总结

打卡任务插件系统提供了灵活的插件化架构：

1. **简单任务**：只需定义任务模板和执行视图

开发者可以根据需求创建各种类型的打卡任务，从简单的计时任务到复杂的交互式任务。
