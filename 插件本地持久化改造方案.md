# 插件本地持久化改造方案

## 问题

当前 `TaskPluginLoader` 的插件下载→编译→缓存全链路都在内存中完成，App 重启后所有已安装插件丢失：

1. `downloadPlugin()` 通过 HTTP `fetch()` 获取代码字符串，不写文件
2. `compileComponent()` 用 `URL.createObjectURL()` 创建临时 Blob URL，`import()` 后立即 `revokeObjectURL()`
3. `pluginCache` 是内存中的 `ref<Map>`，进程结束即销毁

## 改造目标

利用 Electron Main Process 的 Node.js 文件系统能力，将插件代码持久化到本地磁盘。

## 架构

```
Renderer (Vue)  ──IPC──►  Main Process (Node.js)  ──fs──►  本地磁盘
                                                          app.getPath('userData')/plugins/
                                                          ├── plugins.json     (安装清单)
                                                          ├── {pluginId}.js    (插件源代码)
                                                          └── ...
```

## 改动文件清单

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `src/main/index.ts` | 修改 | 新增 6 个 IPC handler，负责插件文件的 CRUD |
| `src/main/preload.ts` | 修改 | 暴露 6 个插件相关 IPC 方法到 `window.electronAPI` |
| `src/renderer/env.d.ts` | 修改 | 声明新增的 `electronAPI` 类型 |
| `src/renderer/taskPlugins/TaskPluginLoader.ts` | 修改 | 改造 install/uninstall，新增启动恢复逻辑 |

## 详细设计

### 1. Main Process (`src/main/index.ts`)

新增 IPC handlers：

- `plugin:save-code` — 保存插件 JS 源码到 `plugins/{pluginId}.js`
- `plugin:load-code` — 从 `plugins/{pluginId}.js` 读取源码
- `plugin:delete-code` — 删除 `plugins/{pluginId}.js`
- `plugin:load-installed` — 读取 `plugins/plugins.json` 返回已安装插件清单
- `plugin:save-manifest` — 将单个插件 manifest 写入 `plugins.json`
- `plugin:delete-manifest` — 从 `plugins.json` 中移除指定插件记录

插件根目录：`join(app.getPath('userData'), 'plugins')`

### 2. Preload (`src/main/preload.ts`)

暴露到渲染进程的 API：

```typescript
window.electronAPI.savePluginCode(pluginId, code)
window.electronAPI.loadPluginCode(pluginId)
window.electronAPI.deletePluginCode(pluginId)
window.electronAPI.loadInstalledPlugins()
window.electronAPI.savePluginManifest(manifest)
window.electronAPI.deletePluginManifest(pluginId)
```

### 3. TaskPluginLoader (`src/renderer/taskPlugins/TaskPluginLoader.ts`)

- `install()`: 下载后调用 `electronAPI.savePluginCode()` + `electronAPI.savePluginManifest()` 持久化
- `uninstall()`: 调用 `electronAPI.deletePluginCode()` + `electronAPI.deletePluginManifest()` 清理
- 新增 `restoreInstalledPlugins()`: 启动时调用 `electronAPI.loadInstalledPlugins()`，逐个从本地读取代码并编译挂载
- `compileComponent()`: 保持不变，仍用 Blob URL 方式（从 IPC 读回代码字符串后编译）

## 数据流

### 安装流程
```
install(pluginId)
  → fetchManifest(pluginId)                    // HTTP: 获取manifest
  → downloadPlugin(pluginId)                   // HTTP: 下载JS源码
  → validateCode(code)                         // 安全校验
  → electronAPI.savePluginCode(id, code)       // IPC → fs.writeFile
  → electronAPI.savePluginManifest(manifest)   // IPC → 更新 plugins.json
  → compileComponent(code)                     // Blob URL → import()
  → reportInstall(pluginId)                    // HTTP: 上报后端
```

### 启动恢复流程
```
restoreInstalledPlugins()
  → electronAPI.loadInstalledPlugins()         // IPC → 读取 plugins.json
  → for each manifest:
      → electronAPI.loadPluginCode(id)         // IPC → fs.readFile
      → validateCode(code)                     // 安全校验
      → compileComponent(code)                 // Blob URL → import()
      → plugins.set(id, instance)              // 挂载到内存
```
