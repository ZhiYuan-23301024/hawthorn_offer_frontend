# 插件系统测试方案

## 一、测试目标

验证插件系统能否完整支持以下流程：
1. **插件创建**：开发者创建一个简单的打卡任务插件
2. **插件上传**：将插件上传到后端服务
3. **插件下载**：前端从后端下载插件
4. **插件安装**：前端加载并挂载插件
5. **插件使用**：用户正常使用插件功能
6. **插件卸载**：前端卸载插件

### 3.2 插件代码

```javascript
// test-daily-checkin.js
const template = `
  <div class="daily-checkin-plugin">
    <h3>{{ title }}</h3>
    <div class="checkin-status">
      <span v-if="checkedIn" class="status-checked">✓ 今日已打卡</span>
      <span v-else class="status-unchecked">○ 今日未打卡</span>
    </div>
    <button 
      @click="handleCheckin" 
      :disabled="checkedIn"
      class="checkin-btn"
    >
      {{ checkedIn ? '已打卡' : '立即打卡' }}
    </button>
    <div class="checkin-count">连续打卡 {{ streak }} 天</div>
  </div>
`

const style = `
  <style>
    .daily-checkin-plugin {
      padding: 20px;
      background: #1e1e1e;
      border-radius: 8px;
      text-align: center;
    }
    .daily-checkin-plugin h3 {
      color: #fff;
      margin-bottom: 16px;
    }
    .status-checked {
      color: #4caf50;
      font-size: 14px;
    }
    .status-unchecked {
      color: #f44336;
      font-size: 14px;
    }
    .checkin-btn {
      margin-top: 16px;
      padding: 8px 24px;
      background: #007acc;
      color: #fff;
      border: none;
      border-radius: 4px;
      cursor: pointer;
    }
    .checkin-btn:disabled {
      background: #666;
      cursor: not-allowed;
    }
    .checkin-count {
      margin-top: 12px;
      color: #888;
      font-size: 12px;
    }
  </style>
`

export default {
  name: 'TestDailyCheckin',
  data() {
    return {
      title: '每日打卡',
      checkedIn: false,
      streak: 0
    }
  },
  mounted() {
    console.log('TestDailyCheckin plugin mounted')
    this.loadStatus()
  },
  methods: {
    loadStatus() {
      const saved = localStorage.getItem('test-checkin-status')
      if (saved) {
        const data = JSON.parse(saved)
        const today = new Date().toDateString()
        this.checkedIn = data.lastCheckin === today
        this.streak = data.streak || 0
      }
    },
    handleCheckin() {
      if (this.checkedIn) return
      
      this.checkedIn = true
      const today = new Date().toDateString()
      const saved = localStorage.getItem('test-checkin-status')
      let streak = 0
      
      if (saved) {
        const data = JSON.parse(saved)
        streak = data.streak || 0
        
        const yesterday = new Date()
        yesterday.setDate(yesterday.getDate() - 1)
        if (data.lastCheckin === yesterday.toDateString()) {
          streak++
        } else if (data.lastCheckin !== today) {
          streak = 1
        }
      } else {
        streak = 1
      }
      
      this.streak = streak
      localStorage.setItem('test-checkin-status', JSON.stringify({
        lastCheckin: today,
        streak
      }))
      
      console.log('Checkin successful! Streak:', streak)
    }
  },
  template,
  style
}
```

### 4.4 步骤四：前端下载并安装插件

创建测试组件 `PluginTest.vue`：

```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'
import { pluginLoader } from '@/plugins/PluginLoader'

const pluginInstance = ref(null)
const isLoading = ref(false)
const error = ref('')
const installedPlugins = ref<string[]>([])

async function loadPlugin() {
  isLoading.value = true
  error.value = ''
  
  try {
    const instance = await pluginLoader.install('test-daily-checkin')
    pluginInstance.value = instance
    installedPlugins.value = pluginLoader.getAllPlugins().map(p => p.manifest.id)
    console.log('Plugin installed successfully:', instance.manifest.name)
  } catch (err) {
    error.value = (err as Error).message
    console.error('Failed to install plugin:', err)
  } finally {
    isLoading.value = false
  }
}

async function unloadPlugin() {
  try {
    await pluginLoader.uninstall('test-daily-checkin')
    pluginInstance.value = null
    installedPlugins.value = pluginLoader.getAllPlugins().map(p => p.manifest.id)
    console.log('Plugin uninstalled successfully')
  } catch (err) {
    error.value = (err as Error).message
    console.error('Failed to uninstall plugin:', err)
  }
}

function refreshPlugins() {
  installedPlugins.value = pluginLoader.getAllPlugins().map(p => p.manifest.id)
}

onMounted(() => {
  refreshPlugins()
})

onUnmounted(() => {
  if (pluginInstance.value) {
    pluginLoader.uninstall('test-daily-checkin').catch(console.error)
  }
})
</script>

<template>
  <div class="plugin-test-container">
    <h2>插件系统测试</h2>
    
    <div class="test-controls">
      <button @click="loadPlugin" :disabled="isLoading || installedPlugins.includes('test-daily-checkin')">
        {{ isLoading ? '安装中...' : (installedPlugins.includes('test-daily-checkin') ? '已安装' : '安装插件') }}
      </button>
      <button 
        @click="unloadPlugin" 
        :disabled="!installedPlugins.includes('test-daily-checkin')"
      >
        卸载插件
      </button>
    </div>
    
    <div v-if="error" class="error-message">{{ error }}</div>
    
    <div class="installed-list">
      <h3>已安装插件:</h3>
      <ul>
        <li v-for="pluginId in installedPlugins" :key="pluginId">{{ pluginId }}</li>

  </div>
</template>
```

## 六、测试注意事项

1. **后端服务必须运行**：确保 Spring Boot 应用在 `http://localhost:8080` 运行
2. **数据库连接正确**：确保 PostgreSQL 数据库配置正确
3. **CORS 配置**：后端需配置允许前端跨域访问
4. **插件状态**：插件必须处于 `PUBLISHED` 状态才能被下载
5. **代码安全性**：测试插件代码不应包含危险操作（如 `eval`、`document.write` 等）

## 七、问题排查

### 常见错误及解决方案

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 404 Not Found | 插件不存在或未发布 | 检查插件ID和状态 |
| 400 Bad Request | 请求参数错误 | 检查 JSON 格式和必填字段 |
| 500 Internal Server Error | 后端服务异常 | 查看后端日志 |
| 插件无法加载 | 代码格式错误 | 检查 JavaScript 语法 |
| 安全检查失败 | 代码包含危险操作 | 修改插件代码移除危险 API |
